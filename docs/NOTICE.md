# Notices

- `orbital.clock` and `orbital.workspaces` are modified clones of the built-in `omarchy.clock` / `omarchy.workspaces`
  (Omarchy, MIT).
- `orbital.dock` is adapted from `claudsondouglas/arc.dock` (MIT, Copyright (c) 2026 Claudson): its app grouping and window
  matching. The original license text is kept in `plugins/orbital.dock/LICENSE-arc.dock`, as MIT requires.
- `orbital.floating-bar` is a fork of `charlieras262/floating-bar` (MIT, Copyright (c) 2026 Charlieras262; license kept in
  `plugins/orbital.floating-bar/LICENSE`). The only change is the `floatGapScale` option in `Bar.qml`.
- `orbital.bar` is original Orbital code and the alternative to `orbital.floating-bar`; only the bar named in `shell.json`'s
  `.bar.id` is ever loaded, so having both installed is expected.
- Not bundled: Omaland and the lock-screen fork (third-party). The theme works without them.

- `orbital.keyboard/flags/*.svg` are from `lipis/flag-icons` (MIT, Copyright (c) 2013 Panayiotis Lipiridis); license text in
  `plugins/orbital.keyboard/LICENSE-flag-icons`. The widget itself is based on Omarchy's keyboard-layout widget (MIT).

- `jankeesvw.notification-center` (MIT, Copyright (c) 2026 Jankees van Woezik) is **not bundled**: `install.sh --full` installs it
  with `omarchy plugin add https://github.com/jankeesvw/omarchy-notification-center.git`, and puts the bell after the clock.
