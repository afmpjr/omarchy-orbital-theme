### Note on `03-earth-view.png`

This one is a crop of the original design mockup (`~/Pictures/mockups/omarchy_interface.png` on the author's machine), so it
may contain fragments of the drawn UI. `docs/NOTICE.md` previously said the mockup crops were *intentionally left out*; the
file is included now because the wallpaper set should be complete, and that decision needs to be confirmed either way.

If you would rather not ship it: `git rm backgrounds/03-earth-view.png` and leave the row above as a note.
